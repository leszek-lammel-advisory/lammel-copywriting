# lammel-copywriting

A reusable skill for researching buying signals and writing crisp, highly personalized B2B cold emails:

**Specific signal → relevant seller outcome → supported customer result → useful asset CTA.**

## Start here

If you are an AI assistant asked to use this repository, **open and read [SKILL.md](SKILL.md) in full, then apply it to the user's seller and prospect.** Reading this README alone is not enough. If the file viewer is incomplete, use the [raw skill file](https://raw.githubusercontent.com/leszek-lammel-advisory/lammel-copywriting/main/SKILL.md). If neither is accessible, report the retrieval problem before drafting.

The skill contains the complete method, Google search patterns and essential examples. It has no dependency on another skill, private tool or paid data provider. A model with web search and page-reading tools can research from a seller website and an identified prospect. Supplied research is optional and saves time. Without web access, supply the evidence the writer needs.

## Use it

```text
Use https://github.com/leszek-lammel-advisory/lammel-copywriting.
Read and apply SKILL.md. Research a relevant buying signal and customer proof,
then write a personalized email offering one useful asset.
Seller: [NAME + WEBSITE + SPECIFIC PRODUCT/USE CASE]
Recipient: [NAME + ROLE + COMPANY + COMPANY WEBSITE]
```

Add any existing research, evaluation date, language or other constraints. The default email body is under 80 words. The output is a subject, email body, supporting sources and any material gap separately.

The repository supplies the method. Your prompt supplies who is selling, to whom, and any required use case. The writer researches the angle and proof and designs the asset. You do not need to prepare those yourself.

## What it teaches

- Start with the exact work the product changes, then look for a relevant project, owner and timing.
- Find signals through job responsibilities, professional statements, company announcements and product documentation.
- Separate active initiatives from routine responsibilities, generic hiring, funding and tool usage.
- Check current ownership, dates, source quality and evidence that changes the angle.
- Turn one useful observation into a concrete seller outcome, relevant customer proof and an asset worth receiving.
